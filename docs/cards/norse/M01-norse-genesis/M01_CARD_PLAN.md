# 6. 默认风格 00：去 AI 味的 Primordial Saga

之前第一版 Ymir 的主要问题是：

```text
背景比主体还抢
星云 / 冰晶 / 浮石 / 云雾 / 光效同时堆叠
所有区域都很精致
CG / AI fantasy wallpaper 味太强
主体和环境缺少视觉层级
```

V2 的核心方向改为：

> **主体优先、背景克制、绘画感、局部精细、整体留白。**

## 6.1 Detail Hierarchy

每张图严格分三级：

```text
一级：脸 / 手 / 核心神物 / Key Moment
      → 清晰、最有对比、最高细节

二级：主体服装 / 身体 / 必要近景
      → 中等细节

三级：背景
      → 大形、柔边、低对比、低纹理密度
```

禁止“全画面每一厘米都精雕细琢”。

## 6.2 Subject Separation

主体必须明显从背景脱离，至少使用两项：

- 主体更亮或更暗；
- 主体与背景有冷暖差；
- 主体边缘更清晰；
- 背景空气透视；
- 背景适度景深；
- 局部而非满屏光线。

## 6.3 背景减法

每张最多：

```text
1 个主要环境奇观
+
1 个次级环境元素
```

例如 Ymir：

```text
主体：Ymir
主要环境：冰火交界
次级环境：原初雾
```

不再同时加入银河、巨大月亮、浮石、几十层冰山、极光、闪电、粒子雨、发光符文、晶体皮肤。

## 6.4 视觉质感

推荐：

```text
painterly
matte
broad readable shapes
restrained brush detail
natural imperfect edges
soft atmospheric background
limited focal sharpness
simple silhouette
```

避免：

```text
hyper-detailed everything
glossy 3D
game key art
cinematic VFX overload
random glowing runes
excessive particles
crystal-covered surfaces
galaxy / nebula as default
over-sharpened micro texture
```

# 9. JSON 作为单卡真源

每张 JSON 当前就建档，不等出图后再补。

生成前：

```text
qa.status = planned / prompt-ready
prompt.draft = 已规划提示词
prompt.final = null
```

真正调用模型后：

```text
prompt.final = 实际发送给模型的完整 Prompt
generation.model = 实际模型
generation.attempt = N
generation.generatedAt = ...
qa.status = review / approved
```

以后重出时直接读取 JSON，而不是重新翻 Markdown 猜当年的要求。
