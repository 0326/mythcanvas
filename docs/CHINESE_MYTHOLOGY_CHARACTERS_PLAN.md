# MythCanvas 中国神话人物体系设计方案

> 状态：Content Design Proposal  
> 版本：V1.0  
> 日期：2026-08-26  
> 适用范围：中国神话人物内容建模、人物扩充、神话详情页、人物页、故事关系、神域关系与后续 AI 出图。  
> 相关文档：`docs/CONTENT_POSITIONING.md`、`docs/CHARACTER_ART_SYSTEM.md`、`.agents/skills/mythcanvas-content-model/SKILL.md`

---

## 0. 结论

当前中国神话只有嫦娥一个 `Character`，不能继续用“想到一个神就加一个角色”的方式扩充。

中国神话与希腊神话最大的差异之一，是它并不存在一套从古至今完全统一、稳定、封闭的“奥林匹斯式神谱”。先秦古神、上古英雄、汉魏仙话、道教神系、佛教中国化、地方民间信仰、宋元以来神仙体系、明清神魔小说长期叠加，同一人物还可能在不同传统里发生身份、形象、关系和神职变化。

因此 MythCanvas 应采用：

```text
中国神话 Mythology
  ↓
Character 人物实体（稳定身份）
  ↓
CharacterInterpretation 历史 / 传统解释层（新增概念）
  ↓
CharacterVariant 年龄 / 服装 / 形态（现有能力，保持正交）
  ↓
Style 画风
  ↓
Artwork

同时：
Character ↔ MythStory ↔ Realm / Scene ↔ Character
```

人物体系不建立一棵伪装成“历史事实”的统一神仙等级树，而是建立 **来源清楚、允许多版本并存的神话人物知识图谱**。

首轮建议：

- 建立约 **90 个中国神话核心人物候选池**；
- P0 先完成 **27 个高认知、高视觉、高故事连接度人物**；
- 以 **7 条编辑脉络**组织用户浏览，而不是按单一宗教等级排序；
- 修正当前“三十三重天 = 中国神话默认天界”的建模问题；
- 为西王母、哪吒、二郎神、炎帝/神农等复杂人物增加“解释层 / 身份关联”，避免错误合并或错误拆分。

# 1. 当前问题

## 1.1 中国神话人物规模严重不足

当前 `src/data/seed.ts` 中，中国神话只有：

```text
嫦娥 Chang'e
```

这会导致：

- `/mythology/chinese/` 无法形成真正的人物谱系；
- 神话故事无法通过人物关系展开；
- 神域只有建筑，没有“谁生活/活动在这里”；
- AI 创作几乎没有可选中国神话人物；
- 中国神话虽然是网站视觉主基调，内容深度反而最弱。

## 1.2 当前世界观存在混用风险

现有 seed 将中国神域 `world-heavenly-palace` 命名为“三十三重天”。

这不适合作为 MythCanvas 中国神话默认天界名称。

“三十三天”首先是佛教宇宙观中的重要概念；中国道教历史上也存在多套不同的“诸天”体系，后世文学、民间叙事又经常互相借用。它们不能被简化成“中国神话统一存在三十三层天宫”。

建议后续将默认聚合世界改为更中性的：

```text
天界 / 天庭 Celestial Realm
```

再在其下按来源建立具体 Realm / Scene，例如：

```text
天界
├── 玉京 / 三清境（道教语境）
├── 紫微天宫 / 紫微垣（星辰与帝君语境）
├── 凌霄天宫（文学 / 民间天庭语境）
├── 月宫
└── 雷部神府等专题 Scene
```

不要把佛教“三十三天”、道教“三十六天”或小说中的天宫描写直接做成一个无来源说明的统一楼层系统。

## 1.3 不能直接照搬“网络神仙排行榜”

常见网络资料会把：

```text
盘古 → 三清 → 玉皇大帝 → 王母娘娘 → 四御 → 五老 → ……
```

拼成一棵整齐的“神仙等级树”。

这种结构对产品很诱人，但历史上往往来自多个时期、多个宗教体系、多个小说版本的再拼装。

MythCanvas 应避免：

- 把不同年代角色强行放进同一时期；
- 把《山海经》形象直接等同于明清小说形象；
- 把道教、佛教、民间信仰混成一个无标签体系；
- 把《西游记》《封神演义》设定当作全部中国神话的“官方设定”；
- 把影视、游戏、动画二创设定反向写进传统神话。

# 2. 中国神话的正确产品模型

## 2.1 不是一棵树，而是多层叠加的网络

推荐从内容产品角度理解为：

```text
A. 先秦及早期神话碎片
   山海经 / 楚辞 / 淮南子等

B. 上古帝王与文化英雄传说
   黄帝 / 炎帝 / 蚩尤 / 尧舜禹等

C. 汉魏六朝以来神仙与方术传统
   西王母形象演变 / 仙人谱系 / 志怪

D. 道教神系
   三清 / 玉皇 / 帝君 / 雷部 / 真武 / 仙真等

E. 中国化佛教与跨传统神祇
   部分神祇在佛教、道教、民间之间迁移、重塑

F. 民间信仰与地方神
   妈祖 / 关帝 / 城隍 / 土地 / 灶神 / 财神等

G. 文学神话
   西游记 / 封神演义 / 白蛇传 / 宝莲灯系统等
```

这些层之间不是互斥关系。

例如：

- 西王母：早期古神 → 汉代长生信仰 → 后世道教与民间“王母”形象；
- 哪吒：佛教源流 → 中国化护法神 → 道教 / 民间神祇 → 宋元明文学塑造；
- 二郎神：地方水神、护国神等多种传统 → 后世与“杨戬”文学身份深度绑定；
- 关羽：历史人物 → 地方信仰 → 国家敕封 → 道教 / 佛教 / 民间共同崇奉；
- 孙悟空：文学角色为核心，同时产生真实民间崇拜与地方信仰。

因此“来源”必须是一等数据。

# 4. 人物来源标签体系

每个 Character 至少拥有以下来源 Facet：

```ts
type TraditionTag =
  | 'ancient-myth'          // 先秦及早期古代神话
  | 'imperial-legend'       // 帝王 / 文化英雄传说
  | 'daoist'                // 道教神系 / 仙真
  | 'buddhist-sinicized'    // 佛教输入后中国化的组成部分
  | 'folk-religion'         // 民间信仰
  | 'local-cult'            // 地方神 / 区域信仰
  | 'literary'              // 神魔小说 / 戏曲 / 话本塑造
  | 'historical-deified';   // 历史人物神格化
```

同一人物可多选。

示例：

```text
哪吒
traditions = [buddhist-sinicized, daoist, folk-religion, literary]

关帝
traditions = [historical-deified, folk-religion, daoist, buddhist-sinicized]

孙悟空
traditions = [literary, folk-religion]

女娲
traditions = [ancient-myth]
```

# 5. 来源时间层

建议增加 `source_period`：

```ts
type SourcePeriod =
  | 'pre-qin'
  | 'qin-han'
  | 'wei-jin-six-dynasties'
  | 'sui-tang'
  | 'song-yuan'
  | 'ming-qing'
  | 'modern-folklore';
```

不是为了给神话“定真实出生日期”，而是告诉内容编辑和 AI：

> 当前使用的是哪个历史阶段形成的叙事 / 图像层。

# 6. 新增 CharacterInterpretation：解决中国神话最关键的问题

现有：

```text
CharacterVariant = age / costume / form / composite
```

不能拿它承载“历史传统差异”。

例如：

```text
西王母
├── 《山海经》早期异神形象
├── 汉代不死 / 昆仑女神形象
└── 后世王母 / 瑶池主神形象
```

这不是“换一件衣服”。

哪吒同样如此：

```text
哪吒
├── 佛教护法源流
├── 宋元中国化神祇
├── 明代《西游记》形象
└── 明代《封神演义》哪吒形象
```

因此建议未来增加：

```ts
type CharacterInterpretation = {
  id: string;
  characterId: string;
  slug: string;
  name: string;

  traditionTags: TraditionTag[];
  sourcePeriod: SourcePeriod;
  sourceRefs: SourceRef[];

  role?: string;
  summary?: string;
  symbols?: string[];
  realmIds?: string[];

  canonicalDesignOverrides?: Record<string, unknown>;
  relationshipScope?: string[];

  confidence: 'high' | 'medium' | 'contested';
};
```

最终组合变成：

```text
Character
+ CharacterInterpretation（哪个历史 / 传统版本）
+ CharacterVariant（该版本下的年龄 / 服装 / 形态）
+ Style
+ Scene
+ OutputSpec
= Generation Recipe
```

这仍然保持 `Style` 与人物身份完全正交。

# 7. 关系图也必须带来源

不要在 Character 主表直接写死：

```text
西王母.spouse = 玉皇大帝
```

因为很多流行关系只是后世小说、戏曲或民间再解释。

建议：

```ts
type CharacterRelation = {
  fromCharacterId: string;
  toCharacterId: string;
  relationType:
    | 'parent'
    | 'child'
    | 'consort'
    | 'sibling'
    | 'master'
    | 'disciple'
    | 'ally'
    | 'rival'
    | 'enemy'
    | 'serves'
    | 'rules-over'
    | 'syncretized-with'
    | 'literary-identity-of';

  interpretationId?: string;
  sourceRefs: SourceRef[];
  confidence: 'high' | 'medium' | 'contested';
};
```

这样才能表达：

```text
二郎神 ↔ 杨戬
relation = literary-identity-of
source = 明清神魔小说层

炎帝 ↔ 神农
relation = syncretized-with
confidence = contested / tradition-dependent
```

而不是简单粗暴做 alias。

# 8. 来源可信度等级

内容生产建议使用 5 级 Source Tier。

## S0 — 早期 / 一手经典文本

优先用于古神和上古故事：

```text
《山海经》
《楚辞》
《淮南子》
《列子》部分传统材料
《尚书》/《史记》等涉及上古传说的材料
```

## S1 — 宗教经典与历史神谱

用于道教、佛教中国化和神仙体系：

```text
《道藏》相关文献
历代道教神谱、仪式文本
佛教汉译经典及中国化宗教文献
碑刻、神像题记、寺庙 / 宫观历史资料
```

## S2 — 古代志怪、神仙传与地方资料

```text
《搜神记》
《列仙传》
《神仙传》
地方志
庙志
民俗记录
```

## S3 — 经典文学

```text
《西游记》
《封神演义》
白蛇故事系统
宝莲灯 / 沉香传说系统
戏曲、话本等长期公共领域传统
```

文学内容可以成为 MythCanvas 的正式内容，但必须标记为 `literary`，不能反向证明更早时期的神话设定。

## S4 — 现代二创 / 流行文化

仅用于“现代传播研究”，禁止作为传统 Canonical Design 依据：

```text
现代电影
动画
游戏
网文
短视频设定
商业角色设计
```

尤其不能直接模仿具体商业 IP 的角色造型。

# 12. Character Canonical Design 应随“解释层”生成

中国人物不能只有一套无来源 Canonical Design。

## 12.1 稳定 Identity Anchors

Character 主实体只保留跨版本仍稳定的身份锚点：

```text
name / aliases
核心身份
长期核心符号
最强识别概念
禁止混淆对象
```

## 12.2 Interpretation Anchors

具体历史形象放在 Interpretation：

### 西王母示例

```text
Character
西王母

Interpretation A — early-shanhaijing
- 原始异神气质
- 昆仑 / 西方边界
- 早期文本中的非宫廷化形象

Interpretation B — han-immortality
- 长生、不死世界
- 汉代仙界视觉传统

Interpretation C — later-queen-mother
- 瑶池
- 女仙之主
- 后世宫廷化王母形象
```

禁止直接把今天最熟悉的“雍容王母”回填成《山海经》时代唯一形象。

### 二郎神示例

```text
Character
二郎神

Interpretation A — local-cult / water-control traditions
Interpretation B — religious warrior deity
Interpretation C — yang-jian-literary
```

视觉生成时用户可以选择“传统版本”，这比简单的“少年 / 战甲 / 觉醒形态”更符合 MythCanvas 的文化产品定位。

```ts
type SourceRef = {
  type:
    | 'primary-text'
    | 'religious-canon'

  period?: string;

```

每一个“有争议的关系 / 神职 / 形象”都应该能追到来源。

# 22. 需要立即修正的认知规则

后续 AI Coding / 内容 Agent 默认遵守：

### Rule 1

**“中国神话”不等于“道教神谱”。**

### Rule 2

**“道教神谱”也不是一套从古至今完全固定的唯一神谱。**

### Rule 3

**《西游记》《封神演义》是中国神话文化的重要组成，但属于文学塑造层。**

### Rule 4

**佛教进入中国后形成的大量中国化神祇，可以参与中国神话关系网，但必须保留来源标签。**

### Rule 5

**民间神并不低于“上古神”，产品不做战力和神阶排行榜。**

### Rule 6

**同一个人物允许有多个历史 Interpretation；不要为了省数据强行选择一个“唯一正确造型”。**

### Rule 7

**`CharacterInterpretation` 与 `CharacterVariant` 不同。**

```text
Interpretation = 哪个历史 / 传统版本
Variant = 该版本下年龄 / 服装 / 形态变化
Style = 怎么画
```

# 23. 研究参考与内容编辑入口

后续人物逐个落库时，优先查一手文献与宗教史 / 神话学研究，不依赖“神仙大全”类聚合站。

建议基础资料线：

```text
古代神话：
《山海经》
《楚辞》
《淮南子》
《搜神记》
《列仙传》
《神仙传》

宗教史：
道教史、道藏与神谱研究
中国民间宗教 / 地方神研究
中国佛教中国化研究

文学：
《西游记》
《封神演义》
白蛇传说相关公共领域文本
宝莲灯 / 沉香相关民间文学
```

现代二手研究可用于确定“哪些说法存在争议”，但具体人物正文最终仍应回落到可引用的来源。

研究层面的关键共识：

- 中国古代神话具有明显的分层生产与神、人混融特征，很难证明曾存在一套自足、静态、统一的古代神话系统；
- 道教历史上不同时期、地区存在不同神谱，并不断吸收地方神与其他传统；
- 因此 MythCanvas 应把“来源与演化”做成产品能力，而不是数据清洗时消除差异。

# 24. 最终产品形态

最终中国神话内容应形成：

```text
                        中国神话
                           │
       ┌───────────────────┼───────────────────┐
       ↓                   ↓                   ↓
     人物谱               神域                故事
   Character             Realm             MythStory
       │                   │                   │
       │         ┌─────────┴─────────┐         │
       │         ↓                   ↓         │
       │       昆仑                月宫        │
       │       天界                东海        │
       │       幽冥                华山        │
       │                                         │
       ├───── 女娲 ───── 女娲补天 ───── 不周山 ─┤
       ├───── 大禹 ───── 鲧禹治水 ───── 九州 ───┤
       ├───── 嫦娥 ───── 嫦娥奔月 ───── 月宫 ───┤
       ├───── 哪吒 ───── 哪吒闹海 ───── 东海 ───┤
       └───── 孙悟空 ─── 大闹天宫 ───── 天界 ───┘
                           │
                           ↓
                        Artwork
                           │
                           ↓
                        AI 创作
```

目标不是做“100 个神仙头像”，而是让用户可以从任何一个人物进入完整神话网络：

> **看见一个人物 → 理解他的版本与来源 → 进入他的故事 → 看见故事发生的神域 → 浏览相关人物与作品 → 创作自己的神话视觉。**

这才是 MythCanvas 中国神话人物体系的完整形态。
